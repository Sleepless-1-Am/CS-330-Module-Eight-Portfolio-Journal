# CS-330-Module-Eight-Portfolio-Journal
This README reflection is based on your desk scene project, including the monitor, keyboard, mug, mouse, notebook, pencil, textures, lighting, and camera controls.

CS-330: Computer Graphics and Visualization

How do I approach designing software?

I learned how to break down a complex 3D scene into smaller shapes and organize them into recognizable objects. I started with reference photos of my desk and planned how to build each object. I also learned to balance visual details with performance. In future projects, I can use this same planning process to make complicated designs easier to manage.

How do I approach developing programs?

I improved my C++ and OpenGL skills by building my scene one milestone at a time. I started with basic shapes, then added camera controls, textures, and lighting. I used reusable functions to keep my code organized and made adjustments as I tested each feature. This taught me to develop programs in smaller steps instead of trying to complete everything at once.

How can computer science help me reach my goals?

This course helped me understand how programming can create interactive 3D environments. I can apply these skills to future computer science courses and possibly create better visual training materials. My main career goal is cybersecurity, and the coding, debugging, and problem-solving skills I practiced will help me continue working toward that goal.
